# Heritage Treasures: An In-Depth Analysis of UNESCO World Heritage Sites in Tableau

## 📌 Project Overview
This project presents a **comprehensive visual analysis of UNESCO World Heritage Sites (2019 dataset)** using **Tableau dashboards, story visualization, and a deployed web interface**.  
The objective is to explore global heritage distribution, cultural vs. natural classifications, and geographic insights through **interactive data visualization**.
